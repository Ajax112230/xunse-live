# 寻色 · 心情配色功能 — 设计规范

2026-07-03

## 概述

在现有 `taiweixiao.com` 原版寻色（输入姓名→匹配传统色）基础上，新增 **心情配色** 功能入口。用户描述当下心情，AI 关键词引擎匹配一组 5 色配色方案，以精致的玻璃弹窗呈现。

核心原则：**保持原版极简诗意体验，新增功能不破坏现有画面。**

---

## 入口

- **位置：**「再探一色」按钮下方，输入区域底部
- **样式：** 一行淡色小字 `💭 或写下心情，获取配色灵感`，`font-size: 12px`, `color: rgba(255,255,255,0.25)`, `letter-spacing: 0.06em`，悬停微微变亮
- **行为：** 点击后弹窗升起

## 心情匹配引擎

输入文字 → 正则关键词匹配 11 种心情维度 → 每个维度对应一组候选色 → 去重 + 色系多样性筛选 → 选出 5 色

| 维度 | 触发词示例 | 候选色系 |
|------|-----------|---------|
| 淡淡忧伤 | 伤心、忧郁、惆怅… | 紫、蓝、灰 |
| 静谧平和 | 安静、禅、放空… | 蓝白、青、绿 |
| 明媚欢快 | 开心、甜、幸福… | 黄、红、橙 |
| 温柔治愈 | 温暖、柔软、拥抱… | 黄、米白、褐 |
| 热烈如火 | 激情、热血、狂野… | 赤、橙、金 |
| 清新自然 | 微风、雨后、花香… | 绿、青、蓝 |
| 浪漫甜蜜 | 心动、约会、思念… | 赤、粉、紫 |
| 孤独哲思 | 独处、沉思、冥想… | 蓝、黑、灰 |
| 复古怀旧 | 往事、岁月、旧时光… | 褐、赤、金 |
| 神秘梦幻 | 星空、梦境、奇幻… | 紫、蓝、青 |
| 秋日私语 | 秋天、金黄、成熟… | 橙、褐、黄 |

## 弹窗容器

### 遮罩层

| 属性 | 值 |
|------|----|
| 背景 | `rgba(0,0,0,0.55)` |
| 模糊 | `backdrop-filter: blur(6px)` |
| 入场动画 | `opacity 0→1, 0.35s ease-out` |
| 关闭方式 | 点遮罩空白处 / 按 Esc / 点右上 ✕ |
| 层级 | `z-index: 100` |

### 卡片主体

| 属性 | 值 |
|------|----|
| 背景 | `rgba(20,20,20,0.88)` + `backdrop-filter: blur(24px)` |
| 边框 | `1px solid rgba(201,169,110,0.15)` |
| 圆角 | `22px` |
| 阴影 | 多层: `0 24px 80px rgba(0,0,0,0.5)` + 内嵌金色微光 |
| 宽度 | `max-width: 500px`, 自适应 |
| 内边距 | `40px 32px 32px` |

### 入场动效 A · 升起式

```css
@keyframes modalSlideUp {
  from { transform: translateY(60px); opacity: 0; }
  to   { transform: translateY(0); opacity: 1; }
}
/* 0.55s cubic-bezier(0.16, 1, 0.3, 1) */
```

### 3D 倾斜交互 — TiltedCard

| 参数 | 值 |
|------|----|
| 旋转幅度 | ±14° |
| 缩放 | hover 时 1.04 |
| Spring 弹性 | damping=30, stiffness=100, mass=2 |
| 适用范围 | 整张玻璃卡片 |

使用纯 JS 实现——`mousemove` → 计算鼠标相对卡片中心的偏移 → 设置 CSS `transform: perspective(800px) rotateX() rotateY()`，配合 `transition` 或 `requestAnimationFrame` 做 spring 缓动。

## 色卡展示

### 默认形态：五圆横排

| 属性 | 值 |
|------|----|
| 排列 | 水平居中，间距 14px |
| 圆大小 | 52×52px，圆形 |
| 颜色 | 纯色填充（无纹理） |
| 光泽 | `radial-gradient` 高光椭圆形在左上，模拟点光源 |
| 发光 | `box-shadow: 0 0 20px` 各色半透明外发光 |
| 色名 | 圆圈下方 22px，`font-size: 11px`，极淡 |
| 悬停 | `scale(1.12)` |

每个圆圈底色来自配色引擎返回的 hex 值，外发光色动态设 `--glow` 变量。

### 右滑形态：水墨色条

| 属性 | 值 |
|------|----|
| 排列 | 垂直堆叠，间距 5px |
| 高度 | 56px |
| 圆角 | 6px |
| 水墨效果 | CSS 方案 A — 三层叠加：主渐变（左浓右淡）+ 纸纤维纹理 + 噪点 |
| 渐变方向 | 左→右：0%~55% 实色，55%~75% 开始渗，75%~100% 渐透明 |
| 色名 | 左对齐内嵌 `padding-left: 14px`，白色 `text-shadow` |
| 悬停 | `translateX(5px)` |

### 形态切换

| 方式 | 底部小圆点指示器 |
|------|----|
| 位置 | 色区与操作按钮之间 |
| 样式 | 两个 8px 圆点，间距 8px |
| 激活态 | 金色 `#c9a96e`，拉长成 24px 胶囊形 |
| 默认态 | 极淡 `rgba(255,255,255,0.12)` |
| 过渡 | `transition: all 0.3s` |
| 点击行为 | 圆珠/色条 instant 切换（非动画过渡） |

## 操作按钮

色区下方三个按钮：

| 按钮 | 行为 |
|------|------|
| 🎨 加入配色 | 将当前 5 色追加到底部配色栏（最多 5 色，超出截断） |
| 💾 导出图片 | Canvas 渲染配色卡片 → `download PNG` |
| 📤 分享 | `navigator.share` 或复制文字到剪贴板 |

样式：`border-radius: 50px`, `font-size: 13px`，普通按钮 `border: 1px solid rgba(255,255,255,0.12)`，主要按钮 `background: rgba(201,169,110,0.15)` + 金色边框。

## 彩蛋：小陌悄悄话

检测条件：`originalText.indexOf('小陌') >= 0`

触发后，在操作按钮上方插入一行：

```
┌───────────────────────────────────────┐
│ 🐱 小陌悄悄说：                        │
│ <随机金句>                             │
└───────────────────────────────────────┘
```

- 背景 `rgba(201,169,110,0.06)`
- 边框 `1px solid rgba(201,169,110,0.12)`
- 文字色 `#c9a96e`
- 圆角 12px
- 从 5 句预设中随机选取一句

## 实现范围

### 需修改

- `index.html` → 新增：入口小字（CSS + HTML + JS）、心情引擎 JS、弹窗完整 CSS + HTML + JS、TiltedCard 3D JS、水墨色条 CSS、小圆点切换 JS、小陌彩蛋 JS

### 不修改

- 现有姓名寻色流程（`getColor`、`showColor`、`showInput`）、WebGL 星空、原版 161 色数据

### 技术要点

- TiltedCard 纯 JS 实现：监听 `mousemove` 计算 `rotateX/rotateY`，使用 `requestAnimationFrame` + 手动 spring 缓动（避免引入 motion/react 依赖）
- 水墨色条为纯 CSS background 叠加，无外部图片/Canvas
- 所有新增代码在同一 `index.html` 内，不新增外部文件（除 galaxy.js 已存在）
